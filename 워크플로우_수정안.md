# GitHub Actions 워크플로우 텔레그램 알림 추가

## 문제
- GitHub Actions는 작동함 (배포 성공)
- 텔레그램으로 알림이 안 옴

## 원인
- 워크플로우에 텔레그램 전송 단계가 없음

## 해결 방법

### 1. GitHub Secrets 설정 필요
Repository → Settings → Secrets and variables → Actions에서:
- `TELEGRAM_BOT_TOKEN`: 텔레그램 봇 토큰
- `TELEGRAM_CHAT_ID`: 채팅 ID

### 2. 워크플로우 수정

기존 `deploy.yml`에 텔레그램 알림 단계 추가:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches:
      - main

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'
          exclude-paths: |
            .git
            .github
            README.md
            deploy.ps1
            wait_and_push.ps1
            .gitignore
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
      
      # 텔레그램 알림 추가
      - name: Send Telegram notification
        if: success()
        uses: appleboy/telegram-action@master
        with:
          token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          to: ${{ secrets.TELEGRAM_CHAT_ID }}
          message: |
            ✅ 배포 완료!
            
            Repository: ${{ github.repository }}
            Branch: ${{ github.ref_name }}
            Commit: ${{ github.sha }}
            Author: ${{ github.actor }}
            
            🌐 URL: https://hwangincheolpb.github.io/cursor-claude-website/
            
            📅 ${{ github.event.head_commit.timestamp }}
      
      # 실패 시 알림
      - name: Send Telegram notification (failure)
        if: failure()
        uses: appleboy/telegram-action@master
        with:
          token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          to: ${{ secrets.TELEGRAM_CHAT_ID }}
          message: |
            ❌ 배포 실패!
            
            Repository: ${{ github.repository }}
            Branch: ${{ github.ref_name }}
            Commit: ${{ github.sha }}
            
            로그를 확인해주세요.
```

## 텔레그램 봇 토큰 발급 방법

1. 텔레그램에서 @BotFather 검색
2. `/newbot` 명령어 입력
3. 봇 이름 설정
4. 토큰 받기
5. GitHub Secrets에 추가

## 채팅 ID 확인 방법

1. 텔레그램에서 @userinfobot 검색
2. 봇과 대화 시작
3. 채팅 ID 확인
4. GitHub Secrets에 추가

## 테스트

워크플로우 수정 후:
1. 커밋 & 푸시
2. GitHub Actions 탭에서 실행 확인
3. 텔레그램 메시지 확인
